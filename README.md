## 🚀 Featured Project

### [KhanixUI](https://khanix-ui.vercel.app) — Real-Time Market Intelligence Dashboard

A full-stack, production-deployed platform I built from scratch to solve a real problem: fragmented, delayed market data that requires juggling five different tools. Live at [khanix-ui.vercel.app](https://khanix-ui.vercel.app).

**What it does:**
- Streams live equity prices via Finnhub WebSocket with sub-second latency
- - Runs an AI-scored news pipeline that ranks headlines by market relevance and source credibility
  - - Fires automated Discord alerts via serverless Vercel Cron — no browser required
    - - Renders a live Sector ETF heatmap across S&P 500, NASDAQ, and DOW indices
      - - Tracks a custom watchlist with real-time WebSocket price updates
       
        - **Stack:** Next.js 14 · TypeScript · Tailwind CSS v4 · Finnhub API · Yahoo Finance · Vercel
       
        - **What building it taught me:** Real-time constraints force a different kind of thinking. WebSocket state management, cron reliability, and API rate limiting aren't abstract concepts — they're engineering decisions with immediate consequences. This project taught me to build systems that fail gracefully, not loudly.
