## 🚀 Featured Project

### [KhanixUI](https://github.com/RealKhanix/KhanixUI) — Real-Time Market Command Center
> Live at: [khanix-ui.vercel.app](https://khanix-ui.vercel.app)
>
> A production-deployed market intelligence dashboard featuring:
> - 📈 **Live ticker prices** via Finnhub WebSocket
> - - 📰 **AI-scored news feed** — categorizes and ranks market-moving headlines
>   - - 🤖 **Automated Discord alerts** — Vercel Cron fires every minute, no browser required
>     - - 📊 **Sector ETF heatmap**, S&P 500 / NASDAQ / DOW indices
>       - - 🔍 **Watchlist** with real-time WebSocket price updates
>         - - ⚡ **High-priority alert scanner** — trusted sources scoring ≥80 trigger instant notifications
>          
>           - **Stack:** Next.js 14 (App Router) · TypeScript · Tailwind CSS v4 · Finnhub API · Yahoo Finance · Vercel
